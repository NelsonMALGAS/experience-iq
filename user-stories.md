# User Stories – Guest Experience & Service Recovery Platform (MVP)

This document defines the **Minimum Viable Product (MVP)** user stories for the Guest Experience & Service Recovery Platform.

---

## 🧍 Guest User Stories

### Issue Submission
- [ ] As a **guest**, I want to submit an issue without creating an account, so that I can report problems quickly and easily.
- [ ] As a **guest**, I want to access the feedback form by scanning a QR code, so that I can report issues from anywhere in the property.
- [ ] As a **guest**, I want to choose a category for my issue, so that my problem is routed to the correct department.
- [ ] As a **guest**, I want to describe my issue in my own words, so that staff understand the problem clearly.
- [ ] As a **guest**, I want to optionally upload a photo, so that I can better explain the issue.

### Transparency & Trust
- [ ] As a **guest**, I want to see the status of my submitted issue, so that I know it is being addressed.
- [ ] As a **guest**, I want to be notified when my issue is resolved, so that I feel acknowledged and valued.
- [ ] As a **guest**, I want my feedback to be anonymous, so that I feel safe reporting issues honestly.

---

## 🧑‍🔧 Staff User Stories

### Authentication & Access
- [ ] As a **staff member**, I want to log in securely, so that only authorized users can access internal systems.
- [ ] As a **staff member**, I want to see only issues related to my department, so that I can focus on relevant tasks.

### Issue Management
- [ ] As a **staff member**, I want to view a real-time list of active issues, so that I can respond quickly.
- [ ] As a **staff member**, I want to accept an issue, so that responsibility is clearly assigned.
- [ ] As a **staff member**, I want to update the status of an issue, so that progress is visible to managers and guests.
- [ ] As a **staff member**, I want to see issue priority levels, so that I know which issues to address first.
- [ ] As a **staff member**, I want to view issue details, so that I fully understand the problem before acting.

### Accountability
- [ ] As a **staff member**, I want my actions to be logged, so that there is clarity on who handled each issue.
- [ ] As a **staff member**, I want to receive notifications when a new issue is assigned to me, so that I don’t miss critical tasks.

---

## 🧑‍💼 Manager User Stories

### Operational Oversight
- [ ] As a **manager**, I want to see all active issues in my property, so that I can maintain operational control.
- [ ] As a **manager**, I want to filter issues by category, department, and priority, so that I can identify problem areas.
- [ ] As a **manager**, I want to see how long issues have been open, so that I can enforce Service Level AgreementS (SLAs).

### SLA & Performance
- [ ] As a **manager**, I want to be alerted when an issue exceeds its SLA, so that I can intervene before guest dissatisfaction increases.
- [ ] As a **manager**, I want to reassign or escalate issues, so that critical problems are resolved quickly.
- [ ] As a **manager**, I want to track staff response times, so that I can measure performance and accountability.

### Reporting
- [ ] As a **manager**, I want to view basic analytics (average resolution time, issue counts), so that I can make data-driven decisions.
- [ ] As a **manager**, I want to see issue trends over time, so that I can proactively prevent recurring problems.

---

## 🧑‍💻 Admin / Executive User Stories

### System Configuration
- [ ] As an **admin**, I want to manage user roles and permissions, so that access is controlled appropriately.
- [ ] As an **admin**, I want to configure issue categories, so that reporting aligns with operational needs.
- [ ] As an **admin**, I want to configure SLA thresholds per category, so that expectations are clearly defined.

### Multi-Property Management
- [ ] As an **admin**, I want to view multiple properties in one dashboard, so that I can oversee operations at scale.
- [ ] As an **admin**, I want to compare performance across properties, so that I can identify top-performing and underperforming locations.

### Governance & Audit
- [ ] As an **admin**, I want all issue actions to be logged, so that the system is audit-ready.
- [ ] As an **admin**, I want to export issue data, so that it can be used for reports or compliance reviews.

---

## 🔔 Notification User Stories

- [ ] As a **staff member**, I want to receive real-time notifications when a new issue is created, so that I can respond immediately.
- [ ] As a **manager**, I want to receive alerts when SLAs are breached, so that I can take corrective action.
- [ ] As a **guest**, I want to receive a confirmation when my issue is resolved, so that I know it was handled.

---

## 🔐 Security & Compliance User Stories

- [ ] As a **system administrator**, I want role-based access control, so that users only see data relevant to their role.
- [ ] As a **system administrator**, I want secure authentication, so that sensitive operational data is protected.
- [ ] As a **system administrator**, I want data isolation per property, so that information does not leak across properties.

---

## 🏁 MVP Scope Summary

The MVP includes:
- [ ] Guest issue submission
- [ ] Real-time staff issue handling
- [ ] Manager oversight & SLA monitoring
- [ ] Basic analytics & reporting
- [ ] Secure role-based access control

---

## 📌 Out of Scope (Post-MVP)
- [ ] AI-powered sentiment analysis
- [ ] Predictive maintenance
- [ ] PMS system integrations
- [ ] Multi-language support
- [ ] Advanced BI dashboards

- [ ] Staff receive issues in real time
- [ ] Managers can identify SLA breaches instantly
- [ ] Executives can view operational performance per property
