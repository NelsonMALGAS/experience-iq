
# User Stories – Guest Experience & Service Recovery Platform (MVP)

This document defines the **Minimum Viable Product (MVP)** user stories for the Guest Experience & Service Recovery Platform.

---

## 🧍 Guest User Stories

### Issue Submission

* [x] As a **guest**, I want to submit an issue without creating an account, so that I can report problems quickly and easily.
* [x] As a **guest**, I want to access the issue form by scanning a QR code, so that I can report issues from anywhere on the property.
* [x] As a **guest**, I want to select an issue category, so that my issue is routed to the correct department.
* [x] As a **guest**, I want to describe my issue in my own words, so that staff clearly understand the problem.
* [x] As a **guest**, I want to optionally upload images, so that I can better explain the issue.

### Transparency & Trust

* [ ] As a **guest**, I want to see the current status of my submitted issue, so that I know it is being addressed.
* [ ] As a **guest**, I want to receive confirmation when my issue is resolved, so that I feel acknowledged.
* [x] As a **guest**, I want the option to submit issues anonymously, so that I feel safe reporting issues honestly.

---

## 🧑‍🔧 Staff User Stories

### Authentication & Access

* [x] As a **staff member**, I want to log in securely, so that only authorized users can access internal dashboards.
* [ ] As a **staff member**, I want to see only issues assigned to my property and department, so that I can focus on relevant tasks.

### Issue Management

* [ ] As a **staff member**, I want to see a real-time list of active issues, so that I can respond quickly.
* [ ] As a **staff member**, I want to accept or be assigned an issue, so that responsibility is clearly defined.
* [ ] As a **staff member**, I want to update the status of an issue (Open, In Progress, Resolved), so that progress is visible to admins and guests.
* [ ] As a **staff member**, I want to see issue priority levels, so that I can address urgent issues first.
* [ ] As a **staff member**, I want to view full issue details (category, description, images), so that I understand the problem before acting.

### Accountability & Communication

* [ ] As a **staff member**, I want my actions on an issue to be logged, so that accountability is maintained.
* [ ] As a **staff member**, I want to receive real-time notifications when an issue is assigned to me, so that I do not miss critical tasks.

---

## 🧑‍💼 Admin User Stories

*(Admins include managers, supervisors, and executives)*

### Operational Oversight

* [x] As a **admin**, I want to log in securely, so that only authorized users can access internal dashboards.
* [ ] As an **admin**, I want to view all active issues for my property or properties, so that I have full operational visibility.
* [ ] As an **admin**, I want to filter issues by category, department, priority, and status, so that I can identify problem areas quickly.
* [ ] As an **admin**, I want to see how long issues have been open, so that I can monitor SLA compliance.

### SLA & Performance Management

* [ ] As an **admin**, I want to be alerted when an issue exceeds its SLA, so that I can intervene before guest dissatisfaction increases.
* [ ] As an **admin**, I want to assign or reassign issues to staff, so that issues are resolved efficiently.
* [ ] As an **admin**, I want to track staff response and resolution times, so that I can measure performance and accountability.

### Analytics & Reporting

* [ ] As an **admin**, I want to view basic analytics (issue counts, resolution times, SLA compliance), so that I can make data-driven decisions.
* [ ] As an **admin**, I want to view issue trends over time, so that I can proactively prevent recurring problems.
* [ ] As an **admin**, I want to compare performance across multiple properties, so that I can identify top-performing and underperforming locations.

---

## 🔔 Notification User Stories

* [ ] As a **staff member**, I want to receive real-time notifications when new issues are created or assigned to me, so that I can respond immediately.
* [ ] As an **admin**, I want to receive alerts when SLAs are breached, so that corrective action can be taken.
* [ ] As a **guest**, I want to receive a notification when my issue is resolved, so that I know it was handled.

---

## 🔐 Security & Governance User Stories

* [ ] As an **admin**, I want role-based access control, so that users only see data relevant to their role.
* [ ] As an **admin**, I want secure authentication for staff and admins, so that operational data is protected.
* [ ] As an **admin**, I want data isolation per property, so that information does not leak across properties.
* [ ] As an **admin**, I want all issue actions to be audit-logged, so that the system is compliance-ready.

---

## 🏁 MVP Scope Summary

The MVP includes:

* [ ] QR-based guest issue submission
* [ ] Real-time issue visibility for staff
* [ ] Issue assignment and status tracking
* [ ] SLA monitoring and escalation
* [ ] Admin dashboards and analytics
* [ ] Secure role-based access control

---

## 📌 Out of Scope (Post-MVP)

* [ ] AI-powered sentiment analysis
* [ ] Predictive maintenance
* [ ] PMS system integrations
* [ ] Multi-language support
* [ ] Advanced BI dashboards

---

## ✅ MVP Success Criteria

* [ ] Guests can submit an issue in under 1 minute
* [ ] Issues appear in staff dashboards in real time
* [ ] Admins can identify SLA breaches instantly
* [ ] Staff accountability is visible through audit logs
* [ ] Admins can view performance per property
